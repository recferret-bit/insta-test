# 01 — Database Schema (Database Entities)

Feature: `F-DB-01`. Engine: PostgreSQL 16, `UTF8`, timezone `UTC`. Extension: `pg_trgm` (bundled contrib).

Conventions: `snake_case`; `uuid` PKs generated by the app (UUIDv7, `DEC-04`); every timestamp is `timestamptz`; every FK has an explicit `ON DELETE` rule; every text column has a length `CHECK` that matches the DTO validation.

## `users`

| Column | Type | Constraints |
|---|---|---|
| `id` | `uuid` | `PRIMARY KEY` |
| `username` | `text` | `NOT NULL`, `UNIQUE`, `CHECK (username ~ '^[a-z0-9._]{3,30}$')` |
| `email` | `text` | `NOT NULL`, `UNIQUE`, `CHECK (email = lower(email) AND char_length(email) <= 254)` |
| `password_hash` | `text` | `NOT NULL` |
| `full_name` | `text` | `NOT NULL DEFAULT ''`, `CHECK (char_length(full_name) <= 60)` |
| `bio` | `text` | `NOT NULL DEFAULT ''`, `CHECK (char_length(bio) <= 150)` |
| `avatar_media_id` | `uuid` | `NULL`, `FK → media_assets(id) ON DELETE SET NULL` (added after `media_assets` exists) |
| `posts_count` | `integer` | `NOT NULL DEFAULT 0`, `CHECK (posts_count >= 0)` |
| `followers_count` | `integer` | `NOT NULL DEFAULT 0`, `CHECK (followers_count >= 0)` |
| `following_count` | `integer` | `NOT NULL DEFAULT 0`, `CHECK (following_count >= 0)` |
| `created_at` | `timestamptz` | `NOT NULL DEFAULT now()` |
| `updated_at` | `timestamptz` | `NOT NULL DEFAULT now()` |

## `sessions`

| Column | Type | Constraints |
|---|---|---|
| `id` | `uuid` | `PRIMARY KEY` |
| `user_id` | `uuid` | `NOT NULL`, `FK → users(id) ON DELETE CASCADE` |
| `token_hash` | `bytea` | `NOT NULL`, `UNIQUE`, `CHECK (octet_length(token_hash) = 32)` |
| `user_agent` | `text` | `NOT NULL DEFAULT ''`, `CHECK (char_length(user_agent) <= 255)` |
| `created_at` | `timestamptz` | `NOT NULL DEFAULT now()` |
| `expires_at` | `timestamptz` | `NOT NULL`, `CHECK (expires_at > created_at)` |
| `revoked_at` | `timestamptz` | `NULL` |

## `media_assets`

| Column | Type | Constraints |
|---|---|---|
| `id` | `uuid` | `PRIMARY KEY` |
| `owner_id` | `uuid` | `NOT NULL`, `FK → users(id) ON DELETE CASCADE` |
| `purpose` | `text` | `NOT NULL`, `CHECK (purpose IN ('post','story','avatar'))` |
| `kind` | `text` | `NOT NULL`, `CHECK (kind IN ('image','video'))`, `CHECK (purpose <> 'avatar' OR kind = 'image')` |
| `mime_type` | `text` | `NOT NULL`, `CHECK (mime_type IN ('image/jpeg','image/png','image/webp','video/mp4','video/webm'))` |
| `storage_key` | `text` | `NOT NULL`, `UNIQUE` |
| `byte_size` | `bigint` | `NOT NULL`, `CHECK (byte_size > 0)` |
| `width` | `integer` | `NULL`, `CHECK (width BETWEEN 1 AND 8192)` |
| `height` | `integer` | `NULL`, `CHECK (height BETWEEN 1 AND 8192)` |
| `duration_ms` | `integer` | `NULL`, `CHECK (duration_ms BETWEEN 1 AND 60000)`, `CHECK (kind = 'video' OR duration_ms IS NULL)` |
| `status` | `text` | `NOT NULL DEFAULT 'uploaded'`, `CHECK (status IN ('uploaded','attached'))` |
| `created_at` | `timestamptz` | `NOT NULL DEFAULT now()` |

## `posts`

| Column | Type | Constraints |
|---|---|---|
| `id` | `uuid` | `PRIMARY KEY` |
| `author_id` | `uuid` | `NOT NULL`, `FK → users(id) ON DELETE CASCADE` |
| `caption` | `text` | `NOT NULL DEFAULT ''`, `CHECK (char_length(caption) <= 2200)` |
| `like_count` | `integer` | `NOT NULL DEFAULT 0`, `CHECK (like_count >= 0)` |
| `comment_count` | `integer` | `NOT NULL DEFAULT 0`, `CHECK (comment_count >= 0)` |
| `created_at` | `timestamptz` | `NOT NULL DEFAULT now()` |
| `updated_at` | `timestamptz` | `NOT NULL DEFAULT now()` |
| `deleted_at` | `timestamptz` | `NULL` |

| Column | Type | Constraints |

| `position` | `smallint` | `NOT NULL` (first-appearance order in caption) |
| — | — | `PRIMARY KEY (post_id, tag)` |

## `notifications`

| Column | Type | Constraints |
|---|---|---|
| `id` | `uuid` | `PRIMARY KEY` |
| `recipient_id` | `uuid` | `NOT NULL`, `FK → users(id) ON DELETE CASCADE` |
| `actor_id` | `uuid` | `NOT NULL`, `FK → users(id) ON DELETE CASCADE`, `CHECK (actor_id <> recipient_id)` |
| `type` | `text` | `NOT NULL`, `CHECK (type IN ('like','comment','follow'))` |
| `post_id` | `uuid` | `NULL`, `FK → posts(id) ON DELETE CASCADE` |
| `comment_id` | `uuid` | `NULL`, `FK → comments(id) ON DELETE CASCADE` |
| `created_at` | `timestamptz` | `NOT NULL DEFAULT now()` |
| `read_at` | `timestamptz` | `NULL` |
| — | — | `CHECK ((type = 'follow' AND post_id IS NULL AND comment_id IS NULL) OR (type = 'like' AND post_id IS NOT NULL AND comment_id IS NULL) OR (type = 'comment' AND post_id IS NOT NULL AND comment_id IS NOT NULL))` |

## Entity-Relationship Overview

```text
users 1─* sessions
users 1─* media_assets ─0..1 users.avatar_media_id
users 1─* posts 1─* post_media *─1 media_assets
             posts 1─* post_hashtags
             posts 1─* comments *─1 users
             posts 1─* post_likes *─1 users
users *─* users  (follows)
users 1─* stories 1─1 media_assets
             stories 1─* story_views *─1 users
users 1─* notifications (recipient, actor) ─0..1 posts / comments
```
